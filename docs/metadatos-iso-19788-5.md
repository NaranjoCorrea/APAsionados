# Metadatos educativos ISO/IEC 19788-5

Estos metadatos describen APAsionados como recurso de aprendizaje. Se ofrece también una versión JSON en `public/metadata/iso-19788-5.json`.

| Elemento educativo | Valor |
|---|---|
| Recurso | APAsionados |
| Tipo de recurso | Aplicación web educativa gamificada |
| Audiencia prevista | Estudiantes que practican citas y referencias APA 7 |
| Contexto educativo | Educación superior y formación inicial docente |
| Actividad de aprendizaje | Práctica guiada, autocorrección, evaluación formativa |
| Método de aprendizaje | Aprendizaje basado en práctica, feedback inmediato y gamificación |
| Comportamiento esperado del estudiante | Responder ejercicios, revisar explicación, repetir y mejorar |
| Dificultad | Progresiva: básica, intermedia, avanzada |
| Tiempo típico de aprendizaje | 20-35 minutos para completar los tres niveles |
| Tipo de interacción | Activa e individual |
| Idioma | Español |
| Evaluación | Informe PDF con intentos, contexto, respuestas y explicación |
| Adaptabilidad | Importación BibTeX y generación automática de ejercicios |
| Accesibilidad prevista | Controles de audio/efectos, reducción de movimiento, navegación web estándar |
