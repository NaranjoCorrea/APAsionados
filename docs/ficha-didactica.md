# Ficha didáctica de APAsionados

## Identificación

- Título: APAsionados.
- Autor: Francisco Luis Naranjo Correa.
- Versión: prototipo interno.
- Idioma inicial: español.
- Tipo de material educativo digital: aplicación web gamificada para práctica individual.
- Norma de referencia para calidad: UNE 71362:2020.
- Norma de referencia para metadatos educativos: ISO/IEC 19788-5.

## Destinatarios

Estudiantes que necesitan practicar el formato APA 7 de citas en texto y referencias bibliográficas. La aplicación está pensada para uso individual, autónomo y sin cuenta de usuario.

## Requisitos previos

- Conocimientos básicos de qué es una cita y qué es una referencia.
- Acceso a un navegador moderno.
- No requiere registro ni conexión a servidor para la práctica base.

## Objetivos didácticos

1. Identificar la estructura básica de una referencia APA 7.
2. Aplicar correctamente autoría, año, título, fuente, DOI/URL y puntuación.
3. Distinguir qué elementos llevan título en cursiva según el tipo de fuente.
4. Relacionar una cita en texto con la referencia correspondiente.
5. Reconocer errores frecuentes en artículos, libros, informes, capítulos y fuentes con varios autores.
6. Practicar la autocorrección mediante soluciones explicadas.

## Competencias y resultados de aprendizaje

- Competencia informacional: citar y referenciar fuentes de forma ética y verificable.
- Competencia académica: aplicar normas formales de escritura científica.
- Competencia digital: importar fuentes BibTeX y usar un recurso interactivo de práctica.

Al finalizar, el estudiante debería poder detectar errores APA 7 comunes y justificar la corrección en términos de formato.

## Metodología

La app utiliza práctica guiada con retroalimentación inmediata. Cada ronda propone ejercicios breves, baraja las opciones y muestra una solución explicada tras responder. La progresión por niveles introduce primero fuentes sencillas y después formatos más complejos.

## Secuencia de aprendizaje

- Nivel 1: orden básico, año, autoría, títulos y cursiva en libros.
- Nivel 2: artículos, DOI/URL, volumen, número, páginas y cursivas.
- Nivel 3: autores múltiples, instituciones y coherencia cita-referencia.
- Reto final: pregunta de mayor dificultad para consolidar cada nivel.
- Reto APAbullante: pregunta final avanzada tras completar el juego.

## Evaluación

La evaluación es formativa. La app registra intentos, aciertos, racha, insignias y nivel alcanzado. El informe PDF permite revisar enunciado, contexto, respuesta del estudiante, solución esperada y explicación.

## Tiempo estimado

- Ronda breve: 5-8 minutos.
- Tres niveles completos: 20-35 minutos, según ritmo del estudiante.
- Revisión del informe: 5-10 minutos adicionales.

## Evidencias exportables

- Informe PDF de resultados.
- Resumen de estadísticas de juego.
- Historial de intentos con feedback.

## Adaptación y crecimiento

El material permite incorporar fuentes personalizadas mediante BibTeX. En el futuro puede ampliarse con bilingüismo español/inglés, generación asistida por API y perfiles de dificultad más adaptativos.
